STYLE REFERENCE IMAGE PLACEHOLDER
==================================

Replace this directory's contents with your style reference image.

The style reference should be:
- A PNG image
- Named "style-reference.png"
- Representative of your desired visual style
- Editorial minimalist illustration on textured paper
- Thin black ink lines, muted colors

This image is used as a reference for Gemini image generation
to maintain visual consistency across all scene images.

Update the STYLE_REFERENCE_PATH in your .env file if you use
a different filename or location.
